# Task 14 - MCU

Implement the specified microcontroller: 16-bit instructions, two 8-bit registers, a carry flag, 512 program-memory words, and 1024 data-memory bytes.

Load program and data from the input block, execute from address `0x000`, and return all data memory when the processor reaches `STOP` or an illegal instruction.

Source: `material_hackathon/14_MCU.pdf`.
