# Task 7 - Bionic Robotic Arm

Solve inverse kinematics for a six-degree-of-freedom robotic arm. Given target positions for picking and placing a rock, calculate the required joint angles; two of the six angles are fixed.

The reference describes the Denavit-Hartenberg model and the equations to use. The hardware task is to implement a deterministic fixed-point control datapath that follows the required packet protocol.

Source: `material_hackathon/07_Bionic_Robotic_Arm.pdf`.
