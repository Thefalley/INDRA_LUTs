# Task 12 - Abacus Romanus

Evaluate prefix Polish-notation expressions written as ASCII using extended Roman numerals. Supported operators are addition, subtraction, and multiplication.

The extended symbols represent values up to 100000 and valid values are 1 through 399999. If an intermediate or final result is outside that range, return the specified error word.
