# Task 15 - LDPC Encoder

Generate the complete set of valid codewords associated with a supplied LDPC parity-check matrix. A valid codeword has a zero syndrome against every row of that matrix.

The core work is deriving or applying the corresponding generator-space logic over GF(2), then producing the required encoded vectors in the task packet format.

Source: `material_hackathon/15_LDPC_Encoder.pdf`.
