# Hackathon 2025

Esta edición se ha identificado por el contenido de su guía oficial: el PDF
`FPGA_Hackathon_2025_Project_Guide.pdf` enumera las tasks 1 a 14 y coincide con
los PDFs de ejercicios guardados aquí.

| Carpeta | Contenido |
| --- | --- |
| [`01_Normas`](01_Normas) | Guía oficial y los enunciados de las 14 tasks. |
| [`02_Proyecto_Referencia`](02_Proyecto_Referencia) | Proyecto base, RTL, testbenches y recursos históricos. |

Primero lee la guía y después el PDF de la task que quieras estudiar. El proyecto
de referencia ayuda a entender el flujo, pero la especificación de cada ejercicio
está en `01_Normas/tasks`.
