# Task 5 - Enigma Encryption

Implement an Enigma-like decoding search. The rotor encoding and advancement rules are supplied; the known beginning of the message identifies the target plaintext.

The task is a brute-force search over rotor positions followed by message reconstruction. The implementation must return the original message through the standard task packet interface.
