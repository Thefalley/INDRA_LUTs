# Task 11 - Voyager's Artifacts

Restore missing cells in a square byte matrix. A missing cell is `0xFF`; valid restored matrices have equal row and column sums.

The input size and square dimension are initially unknown, with a maximum of 4 KiB. If the missing values are not uniquely recoverable, return the input matrix unchanged; otherwise return the restored square.

Source: `hackathon/2026/material/11_Artifacts.pdf`.
