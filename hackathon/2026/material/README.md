# Material oficial — Hackathon 2026

Esta carpeta contiene los documentos de referencia para las tasks de 2026.
Es la fuente de verdad antes de modificar RTL, testbenches o wrappers.

## Orden de lectura

1. `00_Project_Guide.pdf`: contexto y reglas generales del proyecto.
2. `00_Quick_Guide.pdf`: guía rápida del flujo.
3. `00_User_Manual.pdf`: uso de la infraestructura.
4. El PDF cuyo número coincide con la task que vas a realizar.

Por ejemplo, para la task 15 hay que leer `15_LDPC_Encoder.pdf` además de los
documentos generales. `06b_Siemens_Lab_Guide.pdf` complementa la task 6.

No se guardan aquí resultados de simulación ni código de desarrollo: esos viven
respectivamente en `../entrega` y `../team018_repo`.
