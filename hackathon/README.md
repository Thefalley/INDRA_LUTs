# Mapa del hackathon

```
hackathon/
├── 2024/
│   └── referencia_historica/  Proyecto y material de una edición anterior
└── 2026/
    ├── material/               Normas y PDFs oficiales
    ├── team018_repo/           Desarrollo intermedio del equipo
    └── entrega/                Entrega preparada para Jenkins
```

## Cómo usar esta estructura

- **material**: es la fuente de verdad para requisitos, interfaces y métricas.
- **team018_repo**: es donde se desarrolla. No se debe asumir que todo lo que hay
  aquí se presentó al juez.
- **entrega**: es lo que se congeló para evaluación. No se mezcla con pruebas
  posteriores.
- **referencia_historica**: permite consultar una edición pasada sin contaminar
  el trabajo actual.
